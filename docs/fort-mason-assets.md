# Fort Mason stage assets

## Blockout source

The stage uses only Godot 4.7.2 primitive `BoxMesh` and `PlaneMesh` geometry,
`StandardMaterial3D` colors, built-in `Label3D` text, and built-in lights.
No external assets are used by `level/fort_mason.tscn`, so there are no additional
model, texture, or font licenses to distribute for this blockout.

The level is a visual homage to the public Fort Mason / Festival Pavilion
setting. It is not a measured or complete reproduction of the real site.

## Assets not selected

External warehouse models, bridge models, HDRI skies, water shaders, and
third-party fonts were not selected for the MVP because they would add review
and licensing work without improving the required playable outdoor/indoor
blockout. They can be evaluated as separate, provenance-bound follow-up work.
