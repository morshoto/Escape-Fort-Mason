# Dots dialogue font

The dialogue bubble bundles the M PLUS 1 variable font from the Google Fonts
repository so Japanese text renders consistently in the editor and Web export.

- Source: <https://github.com/google/fonts/tree/main/ofl/mplus1>
- License: SIL Open Font License 1.1
- License text: [`player/dots/fonts/OFL.txt`](../player/dots/fonts/OFL.txt)

The complete license is kept beside the font asset as required for
redistribution.
